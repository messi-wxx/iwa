1. 开始使用

1.1 启动页 · 隐私保护提示

第一次打开会弹出对话框，标题「隐私保护提示」。正文说明本应用及腾讯 Bugly、极光推送、高德地图等第三方 SDK 的使用情况。

控件作用
《隐私政策》打开隐私政策全文网页。
同意并继续记下同意，初始化相关能力，再进入登录、首页或首次改密。
不同意并退出关闭应用，不能使用。

1.2 账号登录

标题区：「智慧水务云」「智慧水务 服务民生」；分组标题「账号登录」，副标题「使用水司账号进入外勤工作台」。页底「保障供水安全 服务千家万户」。

控件作用
公司编码填水司代码。空则「请填写公司编码」。
账号外勤账号。空则「请填写账号」。
密码登录密码。空则「请填写密码」。右侧眼睛图标切换明文/密文。
验证码看图输入。点右侧验证码图片可刷新。失败「验证码加载失败，请点击刷新」。空或错「请正确输入验证码」。
我已阅读并同意《隐私政策》必须勾选。点蓝色《隐私政策》可再看全文。未勾选点登录：「请先阅读并勾选同意隐私政策」。
登录提交。成功进首页。停用：「该用户已经停用」。异常：「账号异常，请联系管理员」。首次登录（须改密）：「首次登录必须先修改密码」，进入改密页且没有返回键。配置下载失败：「配置信息下载失败」。

1.3 修改密码

标题「修改密码」。设置里进入时左上角有返回；首次登录进入时隐藏返回，必须改完才能进首页。

控件作用
旧密码 / 新密码 / 确认新密码各有一只眼睛切换显隐。空会提示请填写对应项。两次新密码不一致：「新密码确认不一致」。
确认修改规则：至少 6 位，且包含小写、大写、数字、符号中的任意 3 种（「密码至少6位，并且包含小写字母、大写字母、数字、符号其中3种组合」）。成功：「密码修改成功」。首次改密成功后下载配置并进首页。

2. 首页

标题「智慧水务云」。分组「今日外勤」，副标题「高效服务 · 智慧水务」，欢迎语「欢迎，{姓名}」。宫格两列。

控件作用
右上角齿轮进入设置。
抄表进入「抄表任务」。
换表进入「周检换表任务」。
催费进入催费任务列表。
现场服务进入现场服务查询。
诊断进入「选择水表类型」。
水表标定进入「查询地址」。
管网监测进入「我的关注」。
报装工单进入「我的待处理」。
灰色格子显示「暂无权限」。点击只 Toast，不进入。

若有新版本，弹「版本升级提醒」：「发现新版本，是否立即更新？」按钮「更新」「忽略」，勾选「下次不再提醒」后本次版本不再在首页弹出。

3. 抄表（完整闭环）

首页点「抄表」。整条链路：

首页 · 抄表→ 抄表任务（表册）→ 勾选并同步→ 水表列表→ 抄表详情→ 保存为已抄→ 回表册再同步上传

详情页分两种：BCP 标题为「姓名 + 户号」（有欠费详情、上一户/下一户）；EDC / ITWater 标题「抄表详情」（有最近抄、环境照片、楼栋标定）。

3.1 抄表任务 · 还没有表册

标题「抄表任务」。空页：「本地暂无表册。请先获取表册名单，再勾选需要下载的表册。」

控件作用
返回回首页。若正在多选，先退出多选，不立刻离开。
搜索显示/隐藏输入框，hint「表号、户号、姓名、地址」。键盘搜索：无结果「未查到相关水表」；有结果弹出标题「搜索」的列表（表号、姓名、地址），点一项直接进该表详情，可跨表册。
同步空列表时只获取表册名单，不下载水表明细。成功：「已获取表册名单，请勾选后同步」。服务端没有册：「服务端没有待抄表册」。
获取表册空页中间按钮，与空列表时的同步相同。
下拉刷新同样只刷新表册名单。
NFC 贴卡按卡内表号搜表。0 条「未找到该水表」；1 条进详情；多条弹出选择对话框。
这一步还进不了水表。必须先拿到名单，再勾选下载，卡片上出现「共 n 块 · 未抄 · 已抄」后才能点进去。

3.2 抄表任务 · 表册列表

每张卡片：表册名、状态（进行中 / 已完结）、进度。

看到的内容含义
进行中 / 已完结任务状态。服务端已消失的表册会标成已完结。
共 n 块 · 未抄 · 已抄已下载，可以点进去抄。
未下载只有名单。点进去：「该表册尚未下载，请先勾选后同步」。
操作作用
单击已下载进入该表册的水表列表。
单击未下载不进入，提示先同步。
长按任意表册进入多选。
顶部同步（已有数据且未多选）也是进入多选，不会立刻开传。

3.3 抄表任务 · 多选同步

卡片左侧出现勾选框，底部出现操作栏。

控件作用
勾选框 / 点卡片选中或取消该表册。
是否包含网络表仅 BCP 账号在多选时出现。勾选后同步按网络表类型下载，不勾按普通表。
全选全选 / 取消全选切换。
取消退出多选，底栏收起。
同步同步勾选的表册。未勾选：「请选择表册后再同步」。过程中屏幕常亮。

点「同步」之后的顺序

  1. 刷新配置。
  2. 再拉一遍表册名单并写入本地。
  3. 对每个勾选表册：先上传本地已抄读数和照片；有环境位置再上传位置；再下载服务端最新明细并合并。
  4. 成功：「同步成功」。失败弹窗标题「同步失败」，列出错误表册。
已抄未上传的数据一直留在本机，下载新名单不会冲掉。不要一次勾选过多表册。

3.4 水表列表

从已下载表册点进来。标题是表册名。本页没有同步按钮，上传仍回表册页做。

控件作用
返回回抄表任务。
搜索在本表册内按表号、户号、姓名、地址搜。结果同样弹「搜索」列表再进详情。
全部未删除的全部水表。
未抄还没保存过的表。
已抄已抄 + 已上传都在这一档。
所有分组该表册有分组时才显示。点开选某一组或回到「所有分组」。
下拉刷新 / 上拉加载分页，每页 20 条。
单击一行进详情（BCP 或内部页，由平台决定）。
长按一行仅已抄或已上传可删。标题「确定删除该表吗？」。正文说明会造成数据丢失，换表后若要再抄需删旧表再同步该表册。确认「删除」，取消「取消」。未抄的表长按无效。
NFC刷到本表册内的表则打开详情，并视为已刷卡解锁。

每行：表号、户名、地址、状态（未抄 / 已抄 / 已上传）。已抄 = 只在手机上；已上传 = 服务器已收到。

3.5 抄表详情 · EDC / ITWater

标题「抄表详情」。顶栏只有返回，没有欠费详情。

控件作用
返回回水表列表（或搜索进入时的上一页）。
水表编号 / 水表地址只读。空显示「暂无」。
扩展信息服务端下发的键值（不含联系电话）。
联系电话点号码拨打；空显示「暂无电话」。「编辑电话」改号码，hint「输入电话号码」。
抄表员备注抄表员自己的备注，与下面「抄表备注」不是同一项。
抄表止度本期读数，最多 9 位整数。正常抄表不填：「未填写表度数」。超格式：「水表读数最多九位整数」。
用量有上期读数时自动算差，供核对。
抄表备注默认「正常抄表」。点开「选择备注」。未配置备注：「暂未配置备注信息」。选「其它」必须填「请填写无法抄表具体原因」。
拍照记录 +打开相机拍表盘，最多 3 张。超限：「最多只能上传三张图片」。点缩略图预览。长按删除：「删除操作 / 确定删除该图片吗？」确认「删除」。拒绝相机权限：「您拒绝了使用此功能必须的权限」。水司配置必须拍照则不拍不能保存：「未拍照」。
环境照片水司开启显示环境照时出现。点 + 选「手机相册」或「手机拍照」，进入环境图片编辑。最多 4 张。处理失败：「环境图片处理失败」。有环境照会带定位。
楼栋标定+按当前表号打开标定。表号空：「请输入表号」。
最近抄跳到本表册最近一次已抄。没有：「没有发现最近有抄表」。成功：「已返回到最近的抄表」。即使开了强制刷卡，这一钮仍可用。
保存校验后写入本地，变为「已抄」（此时还没上传）。保存中：「正在保存...」。成功：「保存成功」。
上一块 / 下一块在未抄表之间跳。到头：「已经是第一个/最后一个未抄水表了」。
水司开启「强制刷卡」时：未刷 NFC，保存、上一块、下一块禁用；保存提示「请先刷卡后再保存」。刷对本表「刷卡成功」并解锁；刷到其他表则打开那块表。跳到下一块后会重新上锁，需要再刷。 用量异常会弹「提示」并问是否「继续保存」（小于上期读数、超过设定最大用量、超过平均用量比例等），确认后才落库。

3.6 抄表详情 · BCP

标题为「姓名 + 户号」。没有环境照、楼栋标定、最近抄。读数可带小数（最多 9 位整数 + 3 位小数），超格式会提示「水表读数最多九位整数和三位小数」。水司配置算用量时显示用量差。

控件作用
欠费详情有户号时打开催费详情。户号空则无操作。
欠费信息无欠费「暂无欠费」；有欠费显示红色金额和截止时间。
拨打 / 编辑打电话、改电话。用户信息区也可编辑抄表员备注。
抄表止度 / 备注 / 拍照规则同内部页（读数可小数）。同样最多 3 张、长按删除、强制拍照、用量异常继续保存。
上一户 / 下一户在未抄用户之间跳。强制刷卡时同样会禁用，直到刷卡。
保存只存本地。强制刷卡、校验规则同上。

3.7 保存之后如何闭环

  1. 保存成功后，设置里「自动跳下一块表」打开则按顺序跳下一未抄；关闭则按反序跳。
  2. 列表状态变为「已抄」。服务器此时还没有这笔数据。
  3. 返回「抄表任务」，长按或点同步 → 勾选该表册 → 底栏「同步」：先上传已抄和照片，再下载最新名单。
  4. 上传成功后变为「已上传」。

换账号时本地表册按账号隔离。设置「清除缓存」只清当前账号。

4. 换表

首页「换表」。标题「周检换表任务」。仅 EDC，其它平台：「换表任务仅支持 EDC 平台」。

流程：获取任务名单 → 多选同步 → 任务下水表列表（或地图）→ 换表详情 → 保存 → 再同步上传。

4.1 周检换表任务

空页：「本地暂无换表任务。请先获取任务名单，再勾选需要下载的任务。」按钮「获取任务」。

控件作用
返回多选中先退出多选，否则回首页。
搜索hint「旧表号、新表号、地址」。结果弹列表选表进详情；该表不可换：「该表不可换」。
同步 / 获取任务 / 下拉刷新空列表拉任务名单；有数据则进多选；多选中点同步则上传再下载。底栏：全选 / 取消 / 同步。无「是否包含网络表」。
长按任务进入多选。
单击已下载进该任务水表列表。进度「共 n 块 · 未换 · 已换」。未下载：「请先下载」类提示。
NFC刷卡打开可换表的详情。

任务状态：进行中 / 已完结。同步失败同样弹「同步失败」。

4.2 任务内水表列表

控件作用
搜索在本任务内搜表。
地图展示打开地图页。
未换表 / 已换表筛选，括号内为数量。列表状态还有：不可换、旧表未换、新表未换、已完成。
所有分组有分组时筛选。
单击一行可换进详情；不可换提示「该表不可换」。

4.3 地图展示

控件作用
返回回水表列表。
定位地图回到当前位置。
点标记「换表>>」可换进详情；不可换提示。

图例：未换红色、已换绿色、不需更换灰色，并显示各数量。

4.4 换表详情

标题「换表」。

控件作用
换表方式只换旧表 / 只换新表 / 新旧都换。决定哪些区必填。
户号、收费止度只读核对。
旧表号 / 旧表止度 / 旧表照片核对旧表并拍照。长按照片删除（确认框同抄表）。
新表号可手填。提示「可刷 NFC 写入」。旁蓝牙图标读表号：未连接则扫描；已连接弹「蓝牙已连接」：「当前设备可继续读取新表号。更换设备请先断开再扫描。」按钮「继续使用」「断开重扫」。手机不支持：「手机不支持该蓝牙设备」。蓝牙关：「打开蓝牙」。无定位：「请开启定位」。扫描失败类：「蓝牙连接失败」「未找到可读特征值」。
新表起度、口径、新表照片按现场填写、拍照。
立式 / 卧式安装方式，二选一。
检定机构、检定日期、有效期至点日期弹出「选择日期」。负按钮「清除」可清空日期。
环境照片选「手机相册」或「手机拍照」，进环境图片编辑，最多 4 张。
楼栋标定+进标定。表号空：「请输入表号」。
保存校验。异常时「提示」+「继续保存」。保存中：「正在保存...」。保存后回列表再同步上传。

5. 催费

首页「催费」→ 任务列表 → 点任务进用户/水表列表 → 点用户进「催费详情」。也可在任务列表顶部直接查询。

5.1 催费任务列表 / 用户列表

控件作用
返回回上一页。
刷新重新拉取列表。
查询hint「用户编号、名称、电话等」。无结果「未查找到数据」。有结果弹「查询结果」，点用户直达详情。
任务行 / 用户行进入下级列表或详情。

5.2 催费详情

展示用户信息（姓名、编号、电话、地址、状态、立户日期、用户备注、余额、欠费金额）、欠费信息（月份、水表、起度、止度、用量、结算费用、违约金；无则「暂无欠费信息」）、水表信息（表号、口径、计费性质/状态、结算方式、抄读止度/日期、阀门状态、使用状态、表册、水表备注；无则「暂无水表信息」）。

控件作用
刷新刷新当前用户欠费与水表。
拨打 / 编辑打电话；「编辑电话」改号码。
抄读记录弹「抄表记录」：表号、日期、度数、来源、抄表员、审核员。
开关阀标题「确定进行开关阀？」，正文「请谨慎开关水表阀门，以免产生不必要的纠纷！」。「开阀」执行开阀，「关阀」执行关阀。点关阀不是放弃操作，请看清再点。

上一户 / 下一户在任务内切换用户。

6. 现场服务

首页「现场服务」。先查设备，再按平台进入不同功能。不支持时：「当前平台暂不支持此功能」。拒绝相机：「您拒绝了使用此功能必须的权限」。

6.1 查询页

控件作用
选择水司多水司时出现。进水司列表（可按「水司名称」搜）后回填。
请输入表号手填。也可 NFC 写入。
扫码打开「扫描」，提示「请对准二维码」。可「取消」退出。
查询拉取设备。结果卡：设备名称、识别号、设备编号、铭牌、安装地址、创建时间，以及平台标签 edc / epo / itwater。
现场服务 >>进入「现场功能」。

6.2 现场功能（五项）

入口平台作用
组件更换epo有成品进「成品详情」；否则不支持。
组件识别码更新epo无组件：「该设备无组件」。有则「选择组件」→「输入新的识别码」。
成品识别码更新epo「输入新的识别码」，hint「新的识别码」。扫码或「确定」提交。

6.3 EPO：成品详情与更换组件

控件作用
产品简报打开只读简报网页。
更换组件未出库：「该成品未出库，不能进行更换操作」。已出库进入更换页。
原组件 · 添加把原组件加入新组件列表。
新组件 · 移除从新列表去掉。

13. 常见问题

首页格子是灰的？

账号没有该菜单权限，点了只会「暂无权限」。请管理员在后台开通。

表册是「未下载」，点不进去？

长按或点同步进入多选，勾选后底栏点「同步」。出现「共 n 块 · 未抄 · 已抄」才能进水表列表。

保存了但电脑端还看不到？

保存只写在手机上（已抄）。必须回到「抄表任务」再同步，变成「已上传」后服务端才有。

同步失败会丢已抄数据吗？

不会。可再勾选重试。已抄未上传的读数和照片仍在本地。

保存提示未拍照 / 未填写表度数 / 请先刷卡？

正常抄表必须填止度。水司配置必须拍照则先拍表盘。配置强制刷卡则先 NFC。备注选「其它」必须写原因。

催费里点「关阀」会怎样？

会真正关阀，不是取消对话框。开阀、关阀都会执行对应动作。

换账号后表册不见了？

数据按账号隔离。用回原来的账号即可（未清缓存的前提下）。

退出登录会清本地表册吗？

不会。退出没有确认框，但数据仍按账号留在手机里，除非点了「清除缓存」。

需要哪些系统权限？

拍照与扫码：相机。环境照、蓝牙扫描、地图：定位。推送与管网预警：通知。拒绝后对应功能不可用，可在系统设置里打开。

按当前「智慧水务云」外勤版页面与按钮整理。灰色入口、强制刷卡、是否必拍、是否显示环境照、诊断改数权限等以现场账号与水司配置为准。
